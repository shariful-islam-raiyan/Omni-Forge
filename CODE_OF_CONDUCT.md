# Code of Conduct

OmniForge follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep disagreements focused on technical merit.
Report unacceptable behavior via a
[GitHub Issue](https://github.com/shariful-islam-raiyan/Omni-Forge/issues)
or, for sensitive reports, by following [SECURITY.md](SECURITY.md)'s
private reporting process instead of a public issue.
